# Run locally

1. Install Node.js 20.19+ or 22.12+.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal and run `npm install`.
4. Run `npm run dev` and open the localhost URL printed in the terminal (usually http://localhost:3000).

The supplied hero footage is at `public/videos/hero-background.mp4`. Contact and careers forms use the visitor's email application because the provided source bundle did not include its original backend.
